# Every Tunnel Docs

The documentation of Every Tunnel, in two languages with the same pages:

- **[English](en/README.md)**
- **[Español](es/README.md)**

Each language has two parts:

- **Technical docs** (`en/*.md`, `es/*.md`): how the mod is built, for modders, for AI
  assistants working on the code, and for curious players.
- **Player guide** (`en/guide/`, `es/guide/`): short pages for players. The game shows them
  in the main menu under GUIDE, in the language Minecraft is set to (Spanish for any `es_*`
  language, English otherwise).

When a page changes, change it in both languages in the same commit.
