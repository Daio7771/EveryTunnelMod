# CC0 source recordings

Natural/organic sounds that Python cannot synthesize. **Only CC0 (public domain)
files go here**: no attribution is needed and nothing limits how the mod is
distributed. Check the license on the Freesound page before adding a file; the
license is set per upload, and many Freesound sounds are CC BY or CC BY-NC.

Files are kept exactly as downloaded (only renamed). Cutting, cleanup and conversion
to the mod's `.ogg` files happen in the Python pipeline, so edits can be redone.
