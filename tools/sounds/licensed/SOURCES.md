# Licensed source recordings

Recordings under a license that is **not** CC0 and needs credit. Each one is an exception
the project owner agreed to, and each must be credited in `CREDITS.md` at the repository
root (which ships inside the mod's jar). Everything else goes in `../cc0/`, CC0 only.

Files are kept exactly as downloaded (only renamed). Cutting and conversion to the mod's
`.ogg` files happen in the Python pipeline (`cc0_cuts.py`, `folder="licensed"`).
